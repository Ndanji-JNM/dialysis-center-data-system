# Business Requirements

## Project Purpose

The Dialysis Session Tracking System is a healthcare data analytics project designed to track dialysis treatment records and support clinical and operational analysis through SQL and interactive Power BI dashboards.

## Objectives

- Store patient information.
- Track dialysis treatment sessions.
- Monitor dialysis machine utilization.
- Record staff involved in each session.
- Capture pre- and post-treatment vital signs.
- Record treatment complications.
- Support healthcare data analysis using SQL.
- Provide interactive dashboards using Power BI.

## Intended Users

- Dialysis Technologists
- Nurses
- Nephrologists
- Hospital Administrators
- Data Analysts
- Monitoring and Evaluation Officers

## Scope

The project focuses on hemodialysis treatment data using fictional patient information for learning and portfolio purposes.

It covers patient records, dialysis sessions, clinical measurements, complications, staff activity, and machine operations.

The project does not represent a production clinical information system and is not intended for real patient care or medical decision-making.
