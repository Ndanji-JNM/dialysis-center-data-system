## Business Requirements

### Project Purpose

The Dialysis Session Tracking System is a healthcare data analytics project designed to manage dialysis patient treatment records and support operational decision-making through SQL analysis and interactive Power BI dashboards.

### Objectives

- Store patient information.
- Track dialysis treatment sessions.
- Monitor dialysis machine utilization.
- Record staff involved in each session.
- Capture pre- and post-treatment vital signs.
- Record treatment complications.
- Support healthcare reporting using SQL.
- Provide interactive dashboards in Power BI.

### Intended Users

- Dialysis Technologists
- Nurses
- Nephrologists
- Hospital Administrators
- Data Analysts
- Monitoring & Evaluation Officers

### Scope

This project focuses on hemodialysis treatment data using fictional patient information for learning and portfolio purposes.
